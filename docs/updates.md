# Портал и обновления

Главная и страницы `<game>/about.html` следуют макету RH Games из Figma.
Контент: `catalog-content.json`; шаблоны: `site/index.html`, `templates/details.html`.
Галереи содержат реальные отрендеренные игровые экраны. Обложки взяты из
существующей игровой графики. Источники и хеши: `site/assets/games/sources.json`.
Новые изображения не генерировались. Telegram в интерфейсе портала не используется.

В каталоге остаются `lovec-suiko` и `hk-in-a-row`. «Морок» пока не добавлен.
Страницы запуска по прежним адресам сохранены. `games.json` продолжает фиксировать
Web-релизы; его смысл и порядок публикации не изменились.

Нативные загрузки запрашиваются отдельно:
`https://m9a4xhtu4l.cdn.twcstorage.ru/updates/<game>/stable.json`.
Браузер проверяет schema/game/channel, версию, формат SHA-256, размер и HTTPS-путь своей игры
на закреплённом CDN. Ссылки включаются только для валидного манифеста.
При ошибке CDN игра остаётся доступна в браузере. Версии и размер APK не выдумываются:
веб-версия берётся из games.json, Android — из нативного манифеста.

Скачиванием занимается браузер; клиент не пересчитывает SHA-256 загруженного
бинарника. Файлы через CDN полностью проверяются publisher перед публикацией
stable. Установку APK и проверку его подписи выполняет Android.

Для запросов из браузера CDN должен разрешать CORS GET из
`https://games.rita-hoffman.ru`. Если источник — приватный бакет,
настройте авторизацию CDN к S3; если публичный — чтение опубликованных объектов.
Открывать запись в бакет или передавать S3-ключи браузеру не требуется.

Клиент Web проверяет `versions.json` при старте и возврате на вкладку
(с интервалом не менее минуты), затем раз в 15 минут. При смене закреплённого
коммита появляется уведомление; перезагрузка выполняется только после подтверждения.
Перед ней игроку предлагается вернуться в меню для сохранения партии.
Origin и путь игры остаются прежними, IndexedDB не очищается.
Это не перенос прогресса между Android, Windows и Web.

Для CDN/хостинга: HTML, versions.json и updates/* не кешировать надолго.
Имена движка/PCK содержат коммит; неизменяемые нативные файлы — версию, коммит и хеш.
Изменение каталога не обновляет уже работающий движок без перезагрузки.

Локальные проверки:

```sh
python3 -m unittest discover -s tools/tests -v
GODOT_BIN=/path/to/Godot python3 tools/build_site.py --sources /path/to/pinned/worktrees
python3 -m http.server 8766 --directory dist
```

Для повторного применения UI к тем же уже экспортированным исходным коммитам
доступен --from-existing. Сборщик по-прежнему проверяет коммиты и все файлы
и добавляет страницу about.html в проверяемый манифест каждой игры.

Manrope и Playfair Display поставляются локально по OFL; тексты лицензий
сохранены рядом с файлами шрифтов.


Манифесты нативных загрузок портал читает напрямую с публичного S3 origin с CORS. Файлы APK/ZIP загружаются через CDN. Это исключает зависимость браузерных запросов от кеширования CDN ответа без заголовка Origin. Нативные игры читают манифесты через CDN.
